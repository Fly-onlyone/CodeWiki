# Agents

A coding agent that can read the wiki starts from what is already known about the code: its structure, its history and its risks. It can also write the explanations that CodeWiki cannot write itself.

* [Claude Code plugin](claude-code-plugin.md): the tools, a briefing at the start of each session, and the skill that writes notes.
* [Codex](codex.md): the Codex plugin, with the same tools and briefing.
* [MCP tools](mcp-tools.md): the 27 tools, by what they are for.
* [Agent-written notes](writing-notes.md): who writes what in a note, and auto explaining.
* [Folders kept from coding agents](keep-agents-out.md): keep CodeWiki away from agents in chosen folders.
