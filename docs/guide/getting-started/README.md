# Getting started

These pages take you from nothing to a wiki of your own project.

1. [Install](install.md): run the setup program, or unpack the zip.
2. [Your first wiki](your-first-wiki.md): open a project and let CodeWiki write its wiki.
3. [Updating](updating.md): how the app finds and installs new versions.
4. [Set up semantic search](semantic-search.md): optional. Search by meaning with a model server that you run.
