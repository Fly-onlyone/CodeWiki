The first release of CodeWiki.

- **A wiki of your code, kept up to date.** A backend indexes a repository and writes its notes. The `codewiki` command line, an MCP bridge for coding agents, and a desktop app all read from it.
- **The desktop app** starts on a Home page with your recent projects. It has glass surfaces over the Windows Mica backdrop, and motion you can turn down in Settings.
- **Twelve themes** to choose from the toolbar. Dracula, Nord, Gruvbox and Rosé Pine are drawn as their authors published them.
- **Self-update** from GitHub Releases.
- **Log files** for the app and the backend. The backend stops when the app closes.
