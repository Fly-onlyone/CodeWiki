- **Settings is a page of its own**, with switches and selects. The backend keeps its settings in a file, and it encrypts a saved secret for the current user.
- **Choose the LLM provider and the embedder** in Settings, and test each with one small request. A new embedder takes effect without a restart.
- **The app stays in the tray** when you close its window, and it can start with Windows. A second launch hands over to the running app.
- **More logs.** The backend and the MCP bridge write their own logs. You can change the log level while a program runs, and open the logs folder from the palette or Settings.
- **Hide and show the sidebar and the details pane.**
