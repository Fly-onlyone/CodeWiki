- **Your coding agent explains the notes.** CodeWiki writes each note's facts from the code. A coding agent then writes, through the MCP tools, what the thing is for and how it works. Claude Code's plugin has a `write-notes` skill for this. The built-in writer is gone.
- **A plugin for Codex**, beside the one for Claude Code.
- **Embeddings come from a local server you run:** LM Studio, Ollama, llama.cpp, Lemonade or mistral.rs. The built-in embedding model is gone. After the update, choose a server and its model in Settings.
- **Fuller notes.** Notes explain modules, types and integrations in full, with "What it does" and "Items" sections and pictures in their sections. A note can switch to the agent view.
- **Zoom the whole app** with Ctrl+wheel. Open a diagram in a viewer to enlarge it. At start, the app offers to open the last repository. Error reports to Sentry are opt-in: they stay off until you turn them on.
