- **A setup program.** Download `CodeWiki-0.3.1-windows-x64-setup.exe` and double-click it. CodeWiki then shows in Settings → Apps, where you can also uninstall it. The zip stays, for self-update and for installing by hand.
- **Keep coding agents out of chosen folders.** Add a folder with `codewiki agents`, in Settings → Repositories, or from Home and the palette. The MCP bridge then refuses every tool call there, and the plugins stop the agent at that refusal. A folder that holds a kept one is closed too.
- **Settings → Apps shows the new version** after a self-update.
