- **Auto explaining.** With the CodeWiki plugin, Claude Code explains up to 20 waiting notes in the background when a session starts, through a `note-writer` agent. A switch in Settings → Repositories turns it off. The toolbar's "To explain (N)" opens the list of notes that still wait. Several agents can work at once: each one claims the notes it writes.
- **Review several proposals at once.** The review queue sits beside the open proposal. Tick several and approve or reject them together. A toast tells you when new reviews arrive.
- **Toasts and Windows notifications.** Messages appear in the corner of the window. When the window is hidden or minimized, they go to Windows notifications with CodeWiki's name and logo. Clicking one opens the matching page.
- **The app reconnects on its own.** When the backend goes away, the app starts a new one and carries on. The same happens at startup, and for the embedding server on Settings → Semantic search.
- **Search suggests as you type,** grouped into notes, symbols and files.
- **A new look.** A graph of your notes drifts behind the glass, and you can turn it off in Settings → Appearance. Hover, press and selection are now clearly visible everywhere.
