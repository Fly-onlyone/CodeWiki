- **Choose how many notes a session explains.** Settings → Repositories → Auto explaining has a "Notes per session" choice: 5, 10, 20 (the default), 50, 100 or Unlimited. Claude Code starts one note-writer agent per 20 notes, all at once. `/codewiki:write-notes` also takes a number or `all`.
- **The toolbar fits a narrow window.** In a window about 1000 px wide, or at 125% zoom, the toolbar no longer runs past the window's edge. Buttons turn into icons first, with their names in the tooltips. The search field shortens its hint instead of cutting it.
- **Code health reads well in a narrow window.** The Score column keeps room for its bar and number.
- **The title bar on Home** shows only CodeWiki, not the last repository you opened.
- **Notes no longer get stuck waiting.** A change to a source file that changes none of a note's facts used to block that note's explanation, even after a sync. Now the note can be written.
