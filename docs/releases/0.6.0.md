- **More languages.** CodeWiki now reads C#, Go, Kotlin, C and C++ as well as Rust, Python, TypeScript, JavaScript and Java. Source in any other language is mapped at file level, so every repository gets a wiki of its folders and files. TypeScript path aliases, Python packages without `__init__.py` and pnpm, yarn and bun projects are understood too.
- **Impacted tests beyond Rust.** After a change, `get_impacted_tests`, `codewiki impacted-tests` and the Tests page name the tests to run with the command for each language: `dotnet test`, `go test`, Gradle or Maven, `ctest`, `pytest` and the JavaScript test runners.
- **Find a project from Home.** Once you have opened a project, a search field on Home suggests projects you opened before as you type. The toolbar's new "Open recent" button, after Back, lists the last ones.
- **Notes of deleted code.** When the code a note describes is deleted, the note leaves the wiki without losing written work. Notes you wrote yourself wait on the Review page, where you choose which to delete and which to keep.
- **Git worktrees stay out of the way.** A linked git worktree has no row on Home. The row of its repository says how many worktrees it has.
- **A clickable outline.** A click on an entry of the outline in the details pane glides the note to that heading. The entry of the section you are reading is lit, and the details pane scrolls.
