- **Line endings are no change.** A source file saved with Windows line endings on one machine and Unix ones on another is the same file to CodeWiki now. Before, the same commit could look changed in another checkout: notes were marked as behind the code though nothing had changed, and a wiki synced on one machine was out of date on the next.
- **Check your wiki in CI.** A GitHub Action runs CodeWiki in your repository's own CI: `uses: Fly-onlyone/CodeWiki@action-v1`. It reports CodeWiki's findings to code scanning and can fail a build whose committed wiki is not what the code generates. It runs on Linux and Windows runners. README has the inputs.
- **One larger sync, once.** If your files have Windows line endings, the first sync after this update rewrites the wiki's records of them. No note text changes.
