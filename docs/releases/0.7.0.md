- **Remove a project from Home.** Every row of Recent projects now ends with "Remove from list". It takes the project off the list and nothing else: the folder, its wiki and its index stay, and opening the folder again brings the project back. Removing the open project closes it.
- **A shield for coding agents.** The button that keeps coding agents out of a project is now a shield at the end of its row on Home: outlined while agents may use the project, filled while it is kept from them. A click switches it; where a folder above or inside decides, it leads to Settings.
- **Notes in a repository with Windows line endings can be explained again.** Since 0.6.1 a note's brief said the code had changed right after a sync wherever the files have CRLF line endings. A coding agent was told to stop and could not write those notes, and notes it had written were marked as behind the code after every sync. Both are fixed, and notes explained before this update keep their state.
