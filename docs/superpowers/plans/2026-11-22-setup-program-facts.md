Sources: live docs https://jrsoftware.org/ishelp/ (now the Inno 7 docs), plus the Inno Setup 6.7.4 source and help sources at tag `is-6_7_4` of https://github.com/jrsoftware/issrc (used where the live docs are v7-only). ## 1. Version / download / winget
- Current stable is Inno Setup **7.1.1** ("the recommended version"). The 6 line is still maintained: **6.7.4**. Source: https://jrsoftware.org/isdl.php
- 6.7.4 download: https://github.com/jrsoftware/issrc/releases/download/is-6_7_4/innosetup-6.7.4.exe (href on isdl.php).
- winget: "To install Inno Setup 6 interactively using winget use the following command: `winget install --id JRSoftware.InnoSetup -e -s winget -i`". Inno 7 id is `JRSoftware.InnoSetup.7`. Source: https://jrsoftware.org/isdl.php
- Caution: the docs at jrsoftware.org/ishelp are for 7.x. Everything below that I cross-checked in the 6.7.4 help source (ISHelp/isetup.xml, isx.xml, isxfunc.xml, ispp.xml) behaves the same unless noted.

## 2. Per-user install
- `PrivilegesRequired`: valid "admin, or lowest", default "admin". "when set to lowest, Setup will not request to be run with administrative privileges" (non-administrative install mode). https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm
- `{userpf}`: "The path to the current user's Program Files folder. Only Windows 7 and later supports {userpf}; if used on previous Windows versions, it will translate to the same directory as {localappdata}\Programs." https://jrsoftware.org/ishelp/topic_consts.htm (same text in 6.7.4 isetup.xml line 605)
- Windows side: FOLDERID_UserProgramFiles, "Display Name Programs", "Default Path %LOCALAPPDATA%\Programs". https://learn.microsoft.com/en-us/windows/win32/shell/knownfolderid  => YES, `{userpf}` = `%LOCALAPPDATA%\Programs` on Win 7+. Source calls SHGetKnownFolderPath with that FOLDERID (Setup.MainFunc.pas lines 1811-1819, tag is-6_7_4).
- `{autopf}`: auto constant; table row `autopf | commonpf | userpf`: maps to `{userpf}` in non-administrative install mode, `{commonpf}` otherwise. https://jrsoftware.org/ishelp/topic_consts.htm ; https://jrsoftware.org/ishelp/topic_admininstallmode.htm ("The auto form of the directory and Shell Folder constants is mapped to the user form.")
- Recommendation: with `PrivilegesRequired=lowest`, `DefaultDirName={autopf}\CodeWiki` and `{userpf}\CodeWiki` both give `%LOCALAPPDATA%\Programs\CodeWiki`. `{userpf}\CodeWiki` is the explicit one (also stays per-user if someone passes `/ALLUSERS`... not verified). `{localappdata}\Programs\CodeWiki` also equals it ({localappdata} = "current user's local (non-roaming) Application Data folder").
- Docs example: `DefaultDirName={autopf}\My Program` https://jrsoftware.org/ishelp/topic_setup_defaultdirname.htm

## 3. [Setup] directives
- `AppId`: "AppId also determines the actual name of the Uninstall registry key, to which Inno Setup tacks on "_is1" at the end." May contain constants; keep under 127 chars evaluated. Example `AppId=MyProgram`. https://jrsoftware.org/ishelp/topic_setup_appid.htm
- GUID brace escaping: "A "{" character is treated as the start of the constant. If you want to use that actual character in a place where constants are supported, you must use two consecutive "{" characters. (You do not need to double "}" characters.)" https://jrsoftware.org/ishelp/topic_consts.htm  => write `AppId={{8A3F2C1E-1111-2222-3333-444455556666}` (one extra `{`, single `}`). The docs page for AppId has no GUID example; the rule comes from the constants page.
- `AppName`, `AppVersion`, `AppPublisher`: names confirmed in directive list https://jrsoftware.org/ishelp/topic_setupsection.htm . AppVersion: "also used to set the MajorVersion and MinorVersion values in the Uninstall registry key when possible" https://jrsoftware.org/ishelp/topic_setup_appversion.htm . Source writes `DisplayVersion` from AppVersion, `Publisher` from AppPublisher (see item 4).
- `VersionInfoVersion`: valid "A value in the form of up to 4 numbers separated by dots"; default 0.0.0.0; "Partial version numbers are allowed. Missing numbers will be appended as zero's." (6.7.4 isetup.xml line 6264-6268; live page https://jrsoftware.org/ishelp/topic_setup_versioninfoversion.htm). => must be numeric, e.g. `0.3.1`; no `-rc1` suffixes. (Use `VersionInfoTextVersion`/`AppVersion` for text.)
- `DisableDirPage`: valid auto/yes/no, default `auto` ("If this is set to yes, Setup will not show the Select Destination Location wizard page."). https://jrsoftware.org/ishelp/topic_setup_disabledirpage.htm
- `DisableProgramGroupPage`: valid auto/yes/no, default `auto`. https://jrsoftware.org/ishelp/topic_setup_disableprogramgrouppage.htm
- `DisableWelcomePage`: valid yes/no, **default yes** in both live docs and 6.7.4 source (isetup.xml line 5167): "If this is set to yes, Setup will not show the Welcome wizard page." https://jrsoftware.org/ishelp/topic_setup_disablewelcomepage.htm
- `DisableReadyPage`: yes/no, default `no`. https://jrsoftware.org/ishelp/topic_setup_disablereadypage.htm
- `SetupIconFile`: "Specifies a custom program icon to use for Setup/Uninstall." https://jrsoftware.org/ishelp/topic_setup_setupiconfile.htm
- `UninstallDisplayIcon`: "an icon file, either an executable or an .ico file, for the Uninstall entry in Add/Remove Programs"; example `UninstallDisplayIcon={app}\MyProg.exe,1`. https://jrsoftware.org/ishelp/topic_setup_uninstalldisplayicon.htm
- `OutputDir`: default `Output`; "where the compiler will place the resulting Setup.* files". https://jrsoftware.org/ishelp/topic_setup_outputdir.htm
- `OutputBaseFilename`: default `mysetup`; ".exe" appending not stated on the page (it is appended in practice; NOT stated in docs). Do not use `setup` ("all executables named setup.exe are shimmed by Windows application compatibility"). https://jrsoftware.org/ishelp/topic_setup_outputbasefilename.htm
- `CloseApplications`: valid force/yes/no, **default yes**; when silent "Setup will always close and restart such applications, unless told not to via the command line." Uses Restart Manager. https://jrsoftware.org/ishelp/topic_setup_closeapplications.htm
- `ArchitecturesAllowed` default: 64-bit Setup (Inno 6.3+ and 7 compile 64-bit by default? see note) = x64compatible; `ArchitecturesInstallIn64BitMode` blank = always 32-bit mode. 6.7.4 source: "In most cases, x64compatible should be used instead of x64os, because x64compatible allows x64 apps to be installed on Arm64 Windows 11 systems as well. However, x64os is appropriate in unusual cases where an x64 app/binary is known to require true x64 Windows ... x64 device drivers". "Before Inno Setup 6.3, x64os was named x64." (isetup.xml lines 6383-6393). Live: https://jrsoftware.org/ishelp/topic_setup_architecturesallowed.htm and https://jrsoftware.org/ishelp/topic_setup_architecturesinstallin64bitmode.htm . Doc example: `ArchitecturesAllowed=x64compatible`. For an x64 app write `ArchitecturesAllowed=x64compatible` + `ArchitecturesInstallIn64BitMode=x64compatible`.
- `WizardStyle`: valid values include classic, modern, light, dark, dynamic, polar, slate, windows11, zircon, ...; default `classic`; the official Example1.iss uses `WizardStyle=modern dynamic`. https://jrsoftware.org/ishelp/topic_setup_wizardstyle.htm ; https://raw.githubusercontent.com/jrsoftware/issrc/is-6_7_4/Examples/Example1.iss
- `Compression`: default `lzma2/max` in the live (v7) docs; 6.7.4 example uses `Compression=lzma2`. `SolidCompression`: yes/no, default `no`; "If yes ... all files are compressed at once instead of separately." https://jrsoftware.org/ishelp/topic_setup_compression.htm ; https://jrsoftware.org/ishelp/topic_setup_solidcompression.htm  (Compression default under 6.7.4 not re-checked: NOT VERIFIED; set it explicitly.)

## 4. Uninstall registry key
- Name = AppId + `_is1`: "AppId also determines the actual name of the Uninstall registry key, to which Inno Setup tacks on "_is1" at the end." https://jrsoftware.org/ishelp/topic_setup_appid.htm
- Source: `Result := Format('%s\%s_is1', [REGSTR_PATH_UNINSTALL, UninstallRegKeyBaseName])` (Setup.MainFunc.pas line 390, is-6_7_4). `REGSTR_PATH_UNINSTALL` is the Windows constant `Software\Microsoft\Windows\CurrentVersion\Uninstall` (defined in regstr.h; NOT in the fetched Inno sources, so the literal path is from Windows, not verified here).
- Non-admin mode root: "The [HKA], uninstall info, and font install root keys will be HKEY_CURRENT_USER." https://jrsoftware.org/ishelp/topic_admininstallmode.htm  => `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\<AppId>_is1`. Note: with `AppId={{GUID}` the key name is `{GUID}_is1` (single brace in registry).
- Values written (Setup.Install.pas lines 300-312, is-6_7_4): `DisplayName`, `DisplayIcon`, `UninstallString`, `QuietUninstallString` (`"unins000.exe" /SILENT`), **`DisplayVersion`** (= AppVersion, only if non-empty), `Publisher`, `URLInfoAbout`, `HelpLink`, `HelpTelephone`.

## 5. Code: Exec, ExtractTemporaryFile, {tmp}, Files flags
- `function Exec(const Filename, Params, WorkingDir: String; const ShowCmd: Integer; const Wait: TExecWait; var ResultCode: Integer): Boolean;` Wait = ewNoWait | ewWaitUntilTerminated | ewWaitUntilIdle. "If True is returned and Wait is ewWaitUntilTerminated then ResultCode returns the exit code of the process." "If False is returned then ResultCode specifies the error". "Do not include quotes in the Filename parameter; the function will add them automatically." https://jrsoftware.org/ishelp/topic_isxfunc_exec.htm
- `procedure ExtractTemporaryFile(const FileName: String);` "extracts a file listed in the [Files] section to a temporary directory ... ExpandConstant('{tmp}'). Extracted files are deleted when Setup exits." Use `Flags: dontcopy noencryption`. https://jrsoftware.org/ishelp/topic_isxfunc_extracttemporaryfile.htm
- `function ExtractTemporaryFiles(const Pattern: String): Integer;` wildcard; "When solid compression is enabled, be sure to list your temporary files at (or near) the top of the [Files] section." https://jrsoftware.org/ishelp/topic_isxfunc_extracttemporaryfiles.htm
- `{tmp}`: "Temporary directory used by Setup or Uninstall. ... not the value of the user's TEMP environment variable." https://jrsoftware.org/ishelp/topic_consts.htm
- `dontcopy`: "Don't copy the file to the user's system during the normal file copying stage but do statically compile the file into the installation."; `deleteafterinstall`: "Instructs Setup to install the file as usual, but then delete it once the installation is completed (or aborted)." https://jrsoftware.org/ishelp/topic_filessection.htm

## 6. Failing install from [Code]
- `function PrepareToInstall(var NeedsRestart: Boolean): String;` "You can use this event function to detect and install missing prerequisites and/or to shutdown any application which is about to be updated. Return a non empty string to instruct Setup to stop at the Preparing to Install wizard page, showing the returned string as the error message. ... If Setup is stopped this way, it will exit with a dedicated exit code as described in Setup Exit Codes." (6.7.4 ISHelp/isx.xml lines 229-231; live https://jrsoftware.org/ishelp/topic_scriptevents.htm)
- Exit code in silent mode: source sets `SetupExitCode := ecPrepareToInstallFailed` (= documented code 7, "determined that Setup cannot proceed with installation"; 8 if restart needed), shows the message in a message box, then Abort (Setup.WizardForm.pas, via Context7 /jrsoftware/issrc). Note: /SUPPRESSMSGBOXES still leaves exit code 7.
- Extracting [Files] in it: YES. Official example https://raw.githubusercontent.com/jrsoftware/issrc/main/Examples/CodePrepareToInstall.iss : `Source: "MyProg-Prerequisite-setup.exe"; Flags: dontcopy noencryption` and in the PrepareToInstall path `ExtractTemporaryFile('MyProg-Prerequisite-setup.exe'); ExpandConstant('{tmp}\MyProg-Prerequisite-setup.exe')`. It runs before files are installed (before the in-use check when CloseApplications=yes).
- `CurStepChanged(ssPostInstall)`: Abort does NOT stop setup there. Docs for Abort: "Abort does not cause Setup or Uninstall to exit unless it's called from one of these event functions: InitializeSetup, InitializeWizard, CurStepChanged(ssInstall); InitializeUninstall, CurUninstallStepChanged(usAppMutexCheck), CurUninstallStepChanged(usUninstall)" and "See also PrepareToInstall" (6.7.4 isxfunc.xml lines 358-364). Source: `SetStep(ssInstall, False)` re-raises (fatal), `SetStep(ssPostInstall, True)` handles the exception (Application.HandleException shows it) and setup continues (Setup.MainForm.pas lines 60-75, 235, 254). RaiseException(Msg) shows the message but also does not abort at ssPostInstall; files are already installed by then.
- Documented way to refuse before install: `PrepareToInstall` returning a message (or `InitializeSetup` returning False, or `NextButtonClick`). Files are not yet copied at PrepareToInstall; `CurStepChanged(ssInstall)` is the other pre-copy hook (Abort allowed there per the list above).

## 7. Uninstall
- `function InitializeUninstall(): Boolean;` "Return False to abort Uninstall, True otherwise." (6.7.4 isx.xml line 250-252; https://jrsoftware.org/ishelp/topic_scriptevents.htm). It is called before the confirmation prompt and before anything is removed.
- Exit code: not documented ("The uninstaller returns a non-zero exit code if the user cancels or a fatal error occurs ... any non-zero exit code indicates that the uninstaller was not run to completion" https://jrsoftware.org/ishelp/topic_uninstexitcodes.htm). Source (Setup.Uninstall.pas, is-6_7_4): `InitializeUninstall returned False; aborting.` then `Abort`; `UninstallExitCode: Integer = 1` default (line 44), set to 0 only on success (lines 187, 271), `System.ExitCode := UninstallExitCode` (line 908). => aborted uninstall exits **1** (by source, undocumented).
- `Exec` in uninstall: Exec is a general support function; the docs page https://jrsoftware.org/ishelp/topic_isxfunc_exec.htm does not restrict it to Setup. NOT explicitly verified as allowed in InitializeUninstall (no doc statement). `{app}` in uninstall: constants page says `{app}` = application directory; Uninstall expands it from the install log (ExpandConstant('{app}') in uninstall code is the documented norm; not re-verified by a doc quote). Treat both as NOT VERIFIED except by general practice.
- `function UninstallSilent: Boolean;` "Returns True if Uninstall is running silently, False otherwise." https://jrsoftware.org/ishelp/topic_isxfunc_uninstallsilent.htm
- `[UninstallDelete]`: Type `filesandordirs` "Functions the same as files except it matches directory names also" (removes matched directories and their contents); `files`; `dirifempty`. "The uninstaller processes these entries as the last step of uninstallation." https://jrsoftware.org/ishelp/topic_uninstalldeletesection.htm

## 8. Command line
- Setup (https://jrsoftware.org/ishelp/topic_setupcmdline.htm): `/VERYSILENT` "installation progress window is not displayed" (also reboots without asking if a restart is needed unless /NORESTART); `/SUPPRESSMSGBOXES` "Instructs Setup to suppress message boxes. Only has an effect when combined with /SILENT or /VERYSILENT."; `/NORESTART` "Prevents Setup from restarting the system following a successful installation"; `/SP-` "Disables the This will install... Do you wish to continue? prompt at the beginning of Setup"; `/LOG="filename"` "Same as /LOG, except it allows you to specify a fixed path/filename to use for the log file." (overwritten if exists).
- Setup exit codes (https://jrsoftware.org/ishelp/topic_setupexitcodes.htm): 0 success; 1 failed to initialize; 2 user cancelled before install started; 3 fatal error preparing next phase; 4 fatal error during install; 5 user cancelled during install; 6 forcefully terminated by debugger; 7 "determined that Setup cannot proceed with installation" (PrepareToInstall failure); 8 restart needed to correct the problem. "Any non-zero code means Setup did not run to completion."
- Uninstaller switches (https://jrsoftware.org/ishelp/topic_uninstcmdline.htm): /SILENT, /VERYSILENT, /SUPPRESSMSGBOXES (only with /SILENT or /VERYSILENT), /LOG, /LOG="file", /NORESTART. Exit codes: only "non-zero = not run to completion"; no numbered list is documented.
- Uninstaller file name: `unins000.exe` is conventional; not re-quoted from a doc page here. Registry `QuietUninstallString` = `"<path>\unins000.exe" /SILENT` (source line above) - but exact filename NOT quoted from a doc.

## 9. ISCC
- Options (6.7.4 source ISCC.dpr usage text, https://raw.githubusercontent.com/jrsoftware/issrc/is-6_7_4/Projects/ISCC.dpr): `/O<path>` "Output files to specified path (overrides OutputDir)"; `/O(+|-)` enable/disable output; `/F<filename>` "Specifies an output filename (overrides OutputBaseFilename)"; `/Q` "Quiet compile (print error messages only)"; `/Qp` quiet with progress; `/D<name>[=<value>]` "Emulate #define public <name> <value>" (ISPP mode). Example in source: `iscc /Qp /O"My Output" /F"MyProgram-1.0" ...` and `"/DLic=Trial Lic.txt"`. Docs: https://jrsoftware.org/ishelp/topic_compilercmdline.htm (live page shows the v7 long forms too: `-o<path>`, `-f<filename>`, `-q`) and ISPP section "Extended Command Line Compiler" (ispp.xml line 2157).
- Exit codes: 0 Success; 1 "Command-line parameters were invalid or a fatal error occurred"; 2 "The compile failed". https://jrsoftware.org/ishelp/topic_compilercmdline.htm ; matches ISCC.dpr (Halt(1), ExitCode := 2).
- In script (ispp.xml, 6.7.4): `#define MyAppName "My Program"`; `AppName={#MyAppName}` ("{#MyAppName} is short for {#emit MyAppName}"); `#ifndef Ident` ... `#endif` ("check only for the presence or absence of identifiers defined with #define"); `/DName=Value` defines it public, so `#ifndef Version` / `#define Version "0.0.0"` / `#endif` gives a default. Shell example: `iscc "/DMyAppVersion=1.2.3" CodeWiki.iss`. How `/D` parses the value (string vs expression) not confirmed; if a string is needed use `AppVersion={#MyAppVersion}` which works for text; for the numeric VersionInfoVersion pass plain `1.2.3`. NOT VERIFIED beyond that.

## 10. [Run] postinstall
- Flags (https://jrsoftware.org/ishelp/topic_runsection.htm): `postinstall` "Instructs Setup to create a checkbox on the Setup Completed wizard page."; `nowait` "it will not wait for the process to finish executing before proceeding"; `skipifsilent` "Instructs Setup to skip this entry if Setup is running silently."; `unchecked` "Instructs Setup to initially uncheck the checkbox" (so absent => checked by default); `runasoriginaluser`; `shellexec` for non-exe. Parameters `Description` ("which can include constants") and `WorkingDir` ("The initial current directory for the program").
- Example: `Filename: "{app}\codewiki-app.exe"; WorkingDir: "{app}"; Description: "Launch CodeWiki"; Flags: nowait postinstall skipifsilent` (assembled from the above; not copied from a doc).

## 12. gh release create
- https://cli.github.com/manual/gh_release_create : "Additional release notes can be prepended to automatically generated notes by using the `--notes` flag." So `--notes "text" --generate-notes` => your text is prepended to the generated notes. `--generate-notes`: "Automatically generate title and notes for the release via GitHub Release Notes API" (title generated "unless a title was explicitly passed"). `--notes-file <file>` reads notes from file (`-` = stdin). `--title/-t`. `--verify-tag` aborts if the tag does not exist in the remote. Asset files are positional args after the tag; `file#label` sets a display label.
