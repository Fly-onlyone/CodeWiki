# Fonts Module

> Fonts bundled in the binary.

## Source

- `crates/codewiki-app/src/fonts.rs` — module `codewiki_app::fonts`

## How it works

Main items:

- `MONO_FAMILY` — family name of the bundled code font, checked the same way.
- `UI_FAMILY` — family name of the bundled interface font.
- `register` — register the bundled fonts with the text system.
