# Refactor Module

> Refactoring plan: suggestions derived from facts the index already holds.

## What it does

Nothing here is generated by a model. Each suggestion comes from a measurable condition (a long file, a type with many methods, files that depend on each other in a cycle, a function whose collaborators all live in another file), states the evidence, and lists steps in the order that keeps the code compiling between them. The same index always yields the same plan.

## Source

- `crates/cw-wiki/src/refactor.rs` — module `cw_wiki::refactor`

## How it works

1. `run` in [[codewiki]] and `refactor` in [[Api Module]] call `plan`. `plan` calls `Facts::load`, then `split_files`, then `extract_types`, then `break_cycles`, then `move_functions`. `Facts::load` calls `load`, then `hotspots`, then `dependents_by_file` (all in [[Gitintel Module]]). `split_files` calls `file_health` in [[Health Module]], then `is_test_path` in [[Rustscan Module]], then `lines_of`, then `sibling`, then `snake`, then `prefix_groups`, and 3 more.

Calls are listed in the order of the source; a condition or a loop around a call is not shown.

## Items

- `pub enum Kind` — public enum; used by `Suggestion`.
- `pub struct Suggestion` — public struct; used by `break_cycles`, `extract_types`, `move_functions`, `plan` and 2 more.
- `const GENERIC_PREFIXES: [&str; 12]` — Method-name prefixes that describe access, not a responsibility.
- `const MIN_GROUP: usize` — fewest methods sharing a prefix that make a group worth extracting.
- `const MIN_FUNCTION_GROUP: usize` — fewest free functions sharing a prefix that make a module.
- `const MIN_CLUSTER_LINES: u32` — A type and its methods must span this many lines to earn its own module.
- `const MIN_FOREIGN_LINKS: usize` — links to another file needed before a function is said to belong there.
- `fn lines_of(symbol: &Symbol) -> u32` — private function, returns `u32`; called by `extract_types`, `move_functions`, `split_files`.
- `fn snake(name: &str) -> String` — private function, returns `String`; called by `split_files`.
- `fn sibling(file: &str, stem: &str) -> String` — private function, returns `String`; called by `split_files`.
- `fn prefix_groups<'a>(names: &[&'a str], min: usize) -> Vec<(&'a str, Vec<&'a str>)>` — group names by their first `_`-separated word; groups of at least `min` names, largest first.
- `struct Facts` — facts shared by the detectors.
- `fn split_files(index: &Index, facts: &Facts, out: &mut Vec<Suggestion>) -> Result<()>` — long files and files that reach into many others.
- `fn extract_types(facts: &Facts, out: &mut Vec<Suggestion>)` — types with many methods.
- `fn break_cycles(facts: &Facts, out: &mut Vec<Suggestion>)` — files that depend on each other through calls, type references or trait implementations. `use` re-exports alone do not count.
- `fn move_functions(facts: &Facts, out: &mut Vec<Suggestion>)` — free functions that only work with code in one other file.
- `pub fn plan(index: &Index) -> Result<Vec<Suggestion>>` — every suggestion, highest priority first.

And 6 more private items with no comment.
